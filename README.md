# RapiatFrais

RapiatFrais — notes de frais. Fork de GestiStock, mon projet de BTS, on n'en parle pas.

## C'est quoi

Un logiciel de notes de frais pour Rapiat Corp. Le seul endroit où le patron perd de
l'argent... sauf qu'il ne rembourse rien, donc en fait non.

## Stack (si on peut appeler ça une stack)

- Du PHP. Dans un seul `index.php`. Beaucoup. Comme en 2009.
- Un peu de JS qui ne sert à rien.
- Une base de données ? Non : mon API REST maison sur Cloudflare ("une vraie base managée, c'est payant ?", dixit JMR).
- Hébergé sur du gratuit. Tout est gratuit ici. Sauf mon temps.

## Installation

    git clone https://github.com/mnkz/rapiatfrais
    # et voilà. rien à installer. y'a même aucune dépendance installée. bon courage.
